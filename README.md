   ```bash
   git clone https://github.com/ericktheking34/SeansLifeArchive_Images_ModernSmurfsVillage_Y2025_V8.git
   ```

2. **Navigate to the Directory**:
   Change to the project directory:

3. **Download Images**:
